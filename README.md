# Log Analysis Incident Investigation

## Objective
Analyze simulated authentication logs to determine whether suspicious login activity
indicates a potential brute-force attempt or account compromise.

## Scope and Authorization
This project uses simulated or personally generated log data in an authorized lab
environment. No production, government, employer, customer, or third-party systems
were accessed.

## Tools Used
- Windows Event Viewer or exported authentication logs
- Wireshark, Splunk, Elastic, or spreadsheet analysis
- Python, PowerShell, or Bash, as applicable
- MITRE ATT&CK, where applicable

## Project Status
In progress.

## Planned Deliverables
- Authentication-event timeline
- Findings and severity assessment
- Incident-report writeup
- Recommended containment and remediation actions
- Sanitized evidence and screenshots
